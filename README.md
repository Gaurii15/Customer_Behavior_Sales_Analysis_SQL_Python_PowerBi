# Customer_Behavior_Sales_Analysis_SQL_Python_PowerBi
An end-to-end Customer Shopping Behavior Analysis project integrating Python (EDA &amp; data cleaning), PostgreSQL (business queries), and Power BI (interactive dashboard). Demonstrates skills in ETL, feature engineering, SQL analytics, data visualization, and building business insights from 3,900+ customer transactions.

.

🔍 Project Overview

This project explores how demographic factors, product categories, discounts, subscriptions, and shipping choices influence customer spending behavior.
The goal is to help businesses make data-driven decisions on:

Customer segmentation
Product performance
Revenue drivers
Discount optimization
Subscription value

📊 Key Insights

Female customers generated higher revenue.

Subscribers spent significantly more on average.

Express shipping correlated with higher purchase amounts.

A few product categories dominated total revenue.

Loyal customers contributed the most to repeat sales.
